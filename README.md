# Green Yield

> Eco-friendly yield farming aggregator

## Features

- Auto-compound
- Multi-chain support
- Risk scoring
- Portfolio tracking

## Tech Stack

- Frontend: HTML5, CSS3, JavaScript
- Blockchain: Solidity, Rust, Web3.js
- AI: MiMo V2 Flash, Claude Code

## Installation

```bash
git clone https://github.com/naninu123/green-yield.git
cd green-yield
npm install
npm run dev
```
